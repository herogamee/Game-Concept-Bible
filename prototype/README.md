# Playable prototypes

Start with **[v0.1 — illustrated Willowbrook](web-pixel-rpg-v0.1/README.md)**. This is the current presentation/control reference and recommended playable. From its directory, `npm.cmd run dev` serves http://localhost:4173/; `npm.cmd test` and `npm.cmd run build` require no package install.

**[v0.2 — RPGJS technical experiment](rpgjs-v5-adventurer-v0.2/readme.md)** proves parts of the server-authoritative loop and two-client flow. It is not an accepted product replacement. Its functional tests do not establish visual/control parity. See its acceptance evidence and limits.
