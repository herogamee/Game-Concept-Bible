# Skills & Mastery v0.1

**Date:** 2026-10-02  
**Status:** Combat/Class design proposal for future v0.3 validation  
**Goal:** Deep progression without locking the player into one permanent class choice.

## Core decision proposal

Use a hybrid progression model:

> **Weapon Skills + Adventurer Discipline + Learned Skills + Pattern Magic + Life Skills**

The player's identity should be created by what they practice, discover and choose to carry—not only by a class selected at character creation.

Guild Rank remains separate from all skill power.

# 2. Layer B — Adventurer Disciplines

Disciplines are long-form identities similar to professions/classes but should not hard-lock the player.

Examples:

- Guardian
- Duelist
- Hunter
- Marksman
- Pathfinder
- Tracker
- Field Medic
- Pattern Scholar
- Battle Mage
- Monster Scholar
- Cartographer
- Treasure Seeker
- Survivalist
- Artisan specialist

A player may specialize strongly while retaining basic competency elsewhere.

Disciplines can grant:

- passive efficiencies;
- technique access;
- equipment comfort;
- field utility;
- social recognition;
- mentor access.

---

# 3. Layer C — Learned Skills

Important skills should exist in the world.

Possible sources:

- mentors;
- books;
- Guild instruction;
- factions;
- hidden quests;
- monster research;
- ancient manuals;
- ruins;
- achievements;
- unusual equipment;
- world events;
- training partners;
- cultural schools.

Example:

**Silent Step** should feel more meaningful if learned from a veteran scout after proving patience and route discipline than if it simply appears at Level 20.

This converts progression into story.

---

# 4. Layer D — Pattern Magic

Existing Pattern Magic remains the base cosmology.

Known practice families:

- Heat Exchange
- Impulse
- Sensing
- Binding
- Vital Care

Rules:

- magic does not create unlimited matter;
- range/area/duration cost more;
- healing supports recovery rather than erasing consequences;
- materials/foci matter;
- local interference matters;
- knowledge and practice matter.

Non-mages may learn narrow practical patterns.

Examples:

- Fighter: impulse brace;
- Scout: short sensing pattern;
- Ranger: heat/drying utility;
- Medic: vital-care stabilization.

Mage-oriented disciplines gain:

- deeper pattern libraries;
- better efficiency;
- safer combinations;
- diagnosis;
- counter-patterns;
- complex prepared effects.

# 6. Knowledge is progression

A high-level adventurer can still lack knowledge.

Useful progression includes:

- knowing what a monster eats;
- recognizing tracks;
- understanding regional law;
- identifying a fake relic;
- reading an old map;
- knowing a safe retreat route;
- recognizing a dangerous magical pattern.

Knowledge should sometimes outperform raw damage.

---

# 7. Technique rarity

Not all skills need MMO-style rarity colors.

Useful categories may include:

- Common Practice
- Trained Technique
- Specialist Technique
- School Technique
- Rare Manual Technique
- Lost Technique
- Legendary Technique

Rarity should reflect availability/provenance, not automatically damage.

A rare technique can be highly situational.

---

# 8. Hidden techniques and inheritance

Future Chinese-fantasy-inspired research can inform:

- rare manuals;
- incomplete techniques;
- sealed inheritance rooms;
- mentor lineages;
- lost schools;
- technique fragments;
- dangerous shortcuts;
- unusual training conditions.

Do not directly copy named cultivation techniques or realm ladders.

Translate the appeal into original Adventurer Life systems.

---

# 9. Skill discovery rules

Hidden does not mean arbitrary.

A discoverable technique should have one or more clues:

- NPC rumor;
- book reference;
- environmental evidence;
- weapon inscription;
- mentor hint;
- monster behavior;
- faction record.

Avoid pure wiki bait.

---

# 10. Respec philosophy

Avoid punishing experimentation.

Possible model:

- Weapon Skills: train independently.
- Disciplines: commitment matters but can be retrained with cost/time.
- Learned Skills: retained once learned unless story-specific.
- Pattern Magic: knowledge retained; practical mastery varies.
- Life Skills: persistent professions with specialization choices.

Do not make a player delete a character because they tried the wrong weapon at Rank F.

---

# 11. Build order

For RPGJS v0.2 prototype, keep scope tiny:

1. Sword basic attack.
2. One defensive action.
3. Potion/use item.
4. One enemy behavior set.
5. One utility interaction.

Do not implement the full mastery framework before the basic combat feel is validated.

---

# 12. Future v0.3 questions

Combat & Classes v0.3 should resolve:

- action timing;
- stamina/resource model;
- weapon swap rules;
- armor effects;
- hit reactions;
- party roles;
- threat/aggro needs;
- support solo viability;
- PvE server authority;
- first 3–4 discipline prototypes;
- how many active skills fit browser/mobile controls.

The current document defines progression structure, not final combat balance.
