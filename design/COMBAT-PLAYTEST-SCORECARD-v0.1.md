# v0.3 Combat Playtest Scorecard v0.1

**Date:** 2026-10-03
**Purpose:** Compare four prototype loadouts without turning subjective preference into a fake numerical "best class" ranking.

## Session setup

Keep constant:
- same player HP;
- same enemy HP;
- same arena;
- same enemy set;
- same healing access;
- same equipment Workmanship;
- same objective.

Test:
- Fighter / Sword
- Scout / Spear
- Ranger / Bow
- Mage / Staff-Focus

Rotate order between testers so the first loadout does not always receive the learning penalty.

## Record automatically where feasible

Per encounter:
- loadout;
- completion/retreat/defeat;
- duration;
- damage taken;
- primary attacks attempted;
- primary attacks landed;
- defenses attempted;
- defenses successful;
- technique uses;
- Effort minimum;
- potions used;
- enemy kill count;
- retreat count.

These values diagnose problems; they do not produce a class leaderboard.

## Ask after each loadout

Rate 1–5:

- I understood when my attack was dangerous/active.
- I understood when I was committed in recovery.
- Defense felt useful.
- The weapon encouraged a distinct positioning style.
- I could intentionally retreat.
- Controls felt manageable.
- I would be willing to use this loadout for ordinary F work.

Free response:
- What did this weapon want you to do?
- What felt unfair or unclear?
- What would you change first?
- Did the noncombat identity make sense?

## Cross-loadout questions

After all four:
- Which two felt most different, and why?
- Did any loadout feel strictly safer/better at everything?
- Did any loadout feel unable to complete ordinary F work?
- Did "Aptitude" feel like a starting package rather than a permanent class lock?
- Did Pattern Magic feel like the same world as physical combat?
- Did you notice a reason to retreat/prep rather than attack continuously?

## Red flags

Revise before expanding skills if:
- bow trivializes encounters from unreachable distance;
- spear is simply sword with more range;
- mage feels like a separate mana-game;
- guard/brace/ward/evade are rarely worth using;
- primary attack spam is optimal in every situation;
- player cannot understand recovery commitment;
- one loadout requires a party for ordinary F work;
- tester describes only DPS differences.

## Gate recommendation

Do not promote the v0.3 candidate from prototype direction to stronger design approval until:
- all four loadouts are playable;
- no blocker prevents ordinary F solo work;
- at least three testers can explain the distinct combat language of each after playing;
- no loadout is obviously dominant because of range/safety alone;
- controls remain within the shared browser/mobile input budget.

A larger playtest can follow after this first usability gate.
